# Bliss Yoga and Wellness 🧘‍♀️

A web-based yoga and wellness platform designed to help users explore online yoga programs, book classes, and access their sessions through a dedicated student portal.

## 🌿 About the Project

Bliss Yoga and Wellness provides a platform for online yoga classes and wellness programs. Users can explore different programs, submit bookings, and access class information after their enrollment is verified by the administrator.

The website aims to make online yoga learning accessible through a simple interface and a structured booking process.

## ✨ Features

- **Yoga Programs:** Explore drop-in classes, 12-day and 15-day yoga programs, and therapeutic wellness sessions.
- **Online Booking:** Submit enrollment requests for available programs.
- **Payment Verification:** Submit transaction details for administrator verification.
- **Student Portal:** Access program information and class links after approval.
- **Class Scheduling:** View dated session details and meeting links.
- **Authentication:** Supabase-powered authentication and student data management.
- **Contact Integration:** Quick access to Instagram and WhatsApp for communication.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend and Database:** Supabase
- **Authentication:** Supabase Auth
- **Payment Workflow:** PayPal QR payment and manual transaction verification
- **Development Assistance:** Google AI Studio

## 🔄 How It Works

1. Users visit the website and explore available yoga programs.
2. They select a suitable program and submit their enrollment details.
3. Users complete the payment process and submit their transaction ID.
4. The administrator verifies the payment and approves enrollment.
5. Approved students sign in to the student portal to access their scheduled classes and meeting links.

## 🎯 Project Objective

To create an accessible online platform that simplifies yoga program discovery, enrollment, payment verification, and student access to scheduled classes.

## 🚀 Deployment

The website is hosted using GitHub Pages.

Once configured, the published website can be accessed through its GitHub Pages URL.
